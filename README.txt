PDF PRO — โปรแกรมเปิด แก้ไข และพิมพ์ PDF   (ภาษาไทย / English)
รองรับ: Windows 10, Windows 11, macOS (Intel และ Apple Silicon M1/M2/M3/M4)

────────────────────────────────────────
วิธีเปิดโปรแกรม
────────────────────────────────────────
  macOS   : ดับเบิลคลิก "เปิด PDF PRO.command"
            (ครั้งแรกถ้า macOS ไม่ยอมเปิด: คลิกขวา > Open > Open)
  Windows : ดับเบิลคลิก "เปิด PDF PRO (Windows).bat"

  ต้องมี Python 3.9 ขึ้นไป (แนะนำ 3.12) จาก https://www.python.org/downloads/
  • Mac: ใช้ตัวติดตั้งจาก python.org (เป็น universal2 ใช้ได้ทั้ง Intel และ M-series)
         Python ที่มากับ macOS ใช้ไม่ได้ เพราะ Tk เก่า — ตัวเปิดโปรแกรมจะตรวจให้อัตโนมัติ
  • Windows: ตอนติดตั้ง Python ให้ติ๊ก "Add python.exe to PATH"
  ครั้งแรกโปรแกรมจะติดตั้ง PyMuPDF, CustomTkinter, Pillow ให้เอง (ต้องต่ออินเทอร์เน็ต)
  ถ้าย้ายโฟลเดอร์ไปเครื่องอื่น (เช่น Intel → M-series) ตัวเปิดจะเตรียมใหม่ให้อัตโนมัติ

────────────────────────────────────────
ความสามารถ
────────────────────────────────────────
  หน้าแรก       : แสดงไฟล์ที่เปิดล่าสุดพร้อมภาพหน้าแรก คลิกเพื่อเปิด / คลิกขวาเพื่อลบออกจากรายการ
                  ปุ่ม 🏠 หรือคลิกโลโก้ PDF PRO เพื่อกลับหน้าแรก
  2 ภาษา        : ปุ่ม EN / ไทย มุมขวาบน (จำค่าไว้ให้ครั้งต่อไป)
  โหมด ดู/แก้ไข : ปุ่ม "ดู | แก้ไข" ด้านบน — โหมดดูซ่อนเครื่องมือ อ่านอย่างเดียว ใช้ ←/→ เปลี่ยนหน้า
  พิมพ์          : ปุ่ม 🖨 หรือ ⌘P / Ctrl+P — เลือกเครื่องพิมพ์ ช่วงหน้า จำนวนชุด
                  หรือ "ใช้หน้าต่างพิมพ์ของระบบ" (Mac เปิดผ่าน Preview, Windows ผ่านโปรแกรม PDF หลักของเครื่อง)
  ฟอนต์          : เลือกได้ทุกฟอนต์ที่ติดตั้งในเครื่อง (มีช่องค้นหา + ตัวอย่าง + กรองเฉพาะฟอนต์ไทย)
                  เพิ่มฟอนต์ใหม่เอง: ปุ่ม "เพิ่มฟอนต์จากไฟล์…" ในหน้าต่างเลือกฟอนต์ หรือเมนู ••• > เพิ่มฟอนต์…
                  (รองรับ .ttf .otf .ttc — ฟอนต์จะถูกเก็บไว้ให้ PDF PRO ใช้ได้ตลอด)
  แก้ข้อความเดิม : คลิกข้อความในไฟล์ → ลบของเดิมออกจริง แล้วพิมพ์ใหม่ด้วยฟอนต์/ขนาด/สี/ตัวหนาเดิม
  รูปภาพในไฟล์  : ส่งออกรูปทั้งหมด · คลิกรูปเพื่อ บันทึก / แทนที่ / ลบ
  เครื่องมือ     : ข้อความ · ปิดทับ · ปากกา · ไฮไลต์ · กรอบ · เส้น · ลูกศร · รูปภาพ · ลายเซ็น
  จัดการหน้า    : หมุน · เรียง · ทำสำเนา · แทรกหน้าว่าง · ลบ · แยกหน้า · รวมไฟล์
  อื่น ๆ          : เลิกทำ/ทำซ้ำ · โหมดมืด/สว่าง · ซูม

ปุ่มลัด (Mac ใช้ ⌘ · Windows ใช้ Ctrl)
  O เปิด · S บันทึก · Shift+S บันทึกเป็น · P พิมพ์ · Z เลิกทำ · Shift+Z / Y ทำซ้ำ · D ทำสำเนาวัตถุ
  V เลือก · T ข้อความ · E แก้ข้อความเดิม · W ปิดทับ · P ปากกา · H ไฮไลต์ · R กรอบ · L เส้น · A ลูกศร
  Delete ลบวัตถุ/รูป · ลูกศร เลื่อนวัตถุ · PageUp/PageDown เปลี่ยนหน้า

หมายเหตุ
  • "ปิดทับ" เป็นการปิดด้วยสี ข้อความด้านล่างยังค้นหา/คัดลอกได้
    ถ้าต้องการลบข้อมูลจริง ให้ใช้ "แก้ข้อความ" แล้วลบข้อความให้ว่าง
  • ไฟล์ต้นฉบับไม่ถูกแก้ไข จนกว่าจะเลือกบันทึกทับเอง
  • ค่าตั้ง/ไฟล์ล่าสุด/ฟอนต์ที่เพิ่ม เก็บที่
      Mac:     ~/Library/Application Support/PDF PRO
      Windows: %APPDATA%\PDF PRO
  • ห้ามลบโฟลเดอร์ fonts (มี TH Sarabun New และ Sarabun)
